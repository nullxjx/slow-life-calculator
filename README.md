# 松弛有数 · 躺平生活计算器

一个纯浏览器端的长期生活资金规划工具。默认只需修改城市、年龄、成人数、住房、孩子计划和生活档位；不需要填写资产或收入。不收集数据、不依赖第三方脚本或服务。

## 在线体验

https://nullxjx.github.io/slow-life-calculator/

## 功能

- 25 个城市选项（含其他城市），全部明确标为可编辑的规划假设，不是实时行情。
- 租房、自住房与剩余房贷；医疗随年龄分档增长，80 岁起增加照护。
- 已有孩子或未来一/二孩，分年龄段计养育与教育，22 岁停止支持。
- 独立生活、租金、医疗涨幅和名义利率，逐年现金流折现，不机械套用 4% 规则。
- 基础与压力情景、余额曲线、成本拆解、城市比较和 CSV 测算导出。
- 可选养老金、阶段性净收入、父母赡养，默认不凭空假定养老金资格。
- 响应式布局；所有计算在浏览器内存完成，无埋点、无表单上传。

## 本地使用

需要 Node.js 18+ 执行模型测试，Python 3 启动本地静态预览；线上运行不需要它们。

```sh
npm test
npm run dev
```

打开 http://localhost:4173 。无需安装依赖或构建。

GitHub Pages 使用 `main` 分支的 `/docs` 目录，`docs/` 是 `dist/` 的发布副本。修改 `dist/` 后执行 `node scripts/prepare-pages.mjs` 同步，再提交。测试脚本执行纯函数模型的行为核验。

## 模型口径

逐年收支缺口为 `max(0, 当年总支出 - 当年设定收入)`；所需日常本金为各年缺口以名义利率折现后的总和，第一年按年初支付（不折现）。

`所需本金 = Σ 当年缺口 / (1 + 利率)^距今年数 + 应急医疗储备 + 半年当前日常开支`

余额按 `(年初余额 - 当年缺口) × (1 + 利率)` 递推。超额收入不积累，应急储备不参与日常消费、不计息、不重复折现。终点允许日常本金耗尽，**不是终身保证、只花利息模型或保本承诺**。

压力情景：生活、租金、医疗涨幅各增加 1 个百分点，利率降低 0.5 个百分点（不低于 0）；不代表置信区间或最坏情况。默认 1% 利率、2% 生活及租金涨幅、3% 医疗涨幅、规划到 95 岁，均为可调整假设，不承诺数十年锁息。

详细的成人、住房、孩子、教育、医疗、照护预算见网页“怎么算的”和 `dist/model.js`。两位成人默认同龄；已有与计划中的孩子暂不混合建模。未自动计入购房款、车辆购置、灵活就业养老缴费及父母大额医疗。需自行调整生活费、赡养预算和储备，不应仅据此作出辞职或投资决定。
