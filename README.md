# 松弛有数 · 躺平生活计算器

默认计算“在目标城市全款买一套二手住房 + 此后不依赖工作收入生活”需要准备的总资金。保留长期租房、已有房和有房贷选项。主表单只需要城市、年龄、成人数、住房、孩子计划和生活档位，不要求填写资产收入。

## 在线体验

https://nullxjx.github.io/slow-life-calculator/

页面右上角提供 GitHub 源码入口，点击后在新窗口打开本仓库；手机端同样可见。

## 本地使用

需要 Node.js 18+ 运行模型测试、Python 3 启动本地预览；线上无需这些环境。无第三方运行依赖，无需安装或构建。

```sh
npm test
npm run dev
```

打开 http://localhost:4173 。GitHub Pages 发布 `main` 分支的 `/docs`。修改 `dist/` 或住房数据后，执行 `node scripts/prepare-pages.mjs` 生成静态住房模块并同步 `docs/`。

## 住房与生活必须分开

**总资金 = 一次购房安家款 + 长期生活本金 + 独立应急储备。**

- 默认全款买房：单人 60㎡，两位成人 80㎡，每个孩子再加 20㎡；同一家庭比较城市时面积一致。高级设置可自填面积、单价。
- 房款按 `面积 × 各城样本小区挂牌单价中位数`；不是成交价，不保证同区位、学区、户型或装修条件。
- 购房杂费预算默认房款的 3%，翻新预算 1,000 元/㎡，家具搬家预留 2 万元。这些是可编辑预算，不是法定税率、真实装修报价或税务测算。
- 房款、杂费、安家款在现在一次支付，不再计长期租金，不计入半年生活应急金，也不能拿来计息或当可花本金。
- 买房、已有房、有房贷情形默认每平方米每月 6 元物业维修预算；有房贷者额外计剩余月供。不计未来卖房所得。
- 长期租房按同一面积乘以各城租金挂牌单价中位数；不另计购房款。
- 大理和“其他城市”缺少本次同口径住房数据，买房或租房时须在高级设置补单价或月租，不使用其他城市数据假装已覆盖。

## 城市数据与比较口径

住房数据来自中指云公开页面，月份统一为 **2026-10**，于 **2026-11-16** 核对。保存的只有 23 城价格事实和来源，无联系人、账户、追踪信息；浏览器不实时抓取。

- [二手住宅价格指数与编制口径](https://www.cih-index.com/data/index/esfHouse.html)：样本小区挂牌价中位数，非成交均价。
- [住宅租金指数与编制口径](https://www.cih-index.com/data/index/rentIndex.html)：样本小区挂牌单位面积租金中位数，非具体房源报价。
- 事实快照在 `data/housing-market-2026-10.json`；`dist/housing-data.js` 为发布生成模块。

**城市生活费和养育教育系数仍是规划假设，不是官方均值或真实物价指数。** 不用房价系数放大所有消费，也不为了拉大城市差距而改系数。

城市比较只替换城市；家庭、面积、生活档位、利率、规划期等相同。空白项使用各城住房基准，自填开支、面积与购房单价在所有城市保持一致，选中比较卡后金额与卡片一致。若自填了统一购房单价，城市房价差异自然不会体现；清空可恢复各城价格。

## 长期生活现金流

`长期生活本金 = Σ max(0, 当年支出 - 当年设定收入) / (1 + 名义利率)^距今年数`

第一年按年初支付，不折现；剩余资金按年计息。超额收入不积累。应急医疗储备与半年当前日常开支独立留存，不计利息、不重复计日常消费。

- 默认利率 1%，生活及租金年涨幅 2%，医疗照护年涨幅 3%，均为情景假设，不承诺长期锁息。
- 默认规划到 85 岁，可在高级设置改到 95 岁或更高。终点允许日常资金耗尽，不是寿命预测、上限或终身保障，终点之后开支未计入。
- 压力情景：生活、租金、医疗涨幅各加 1 个百分点，利率减 0.5 个百分点（最低 0）；当前购房款不变。不是最坏情况或置信区间。
- 首胎按 35 岁自动推算，已满 35 岁按当年开始，二孩隔 3 年；不是人口统计结论或生育建议。已有孩子按实际年龄计算，支持到 22 岁前，不重复计已发生生育费。
- 医疗随年龄分档上升，80 岁起增加照护；两位成人默认同龄。养老金与其他收入默认 0，不推定领取资格。
- 未自动计车辆购置、灵活就业养老缴费、父母大额医疗等，可补入相关预算和储备。

## 隐私与风险

计算完全在浏览器内存完成，无第三方脚本、埋点、表单上传或填写参数持久化。CSV 由用户点击后在本地生成。托管方仍可能按其政策记录正常网页访问日志。

这是规划情景工具，不是投资、医疗、保险、房产或税务建议。真实房源、购房资格、税费、医疗意外、长期利率和通胀均可能超出假设，不应仅凭此页决定辞职或购房。
